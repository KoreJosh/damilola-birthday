DAMILOLA BIRTHDAY EXPERIENCE
============================

This is a mobile-first, TikTok-style vertical birthday story for Oluwadmilola.

WHAT IS INCLUDED
- index.html — the complete experience
- images/ — your supplied images in the requested sequence
- Music placeholder — the HTML expects a file named:
  ordinary-by-alex-warren.mp3

IMPORTANT MUSIC NOTE
The site is prepared for the song "Ordinary" by Alex Warren, but the audio file itself is not included.
Add an MP3 you are legally allowed to use and name it exactly:
ordinary-by-alex-warren.mp3
Place it in this same folder as index.html.

SEQUENCE
1. Birthday design (start)
2-5. The four text/message designs together
6-13. Mixed personal photos
14. Birthday design (end)

HOW TO PUT IT ONLINE WITH GITHUB PAGES
1. Create a new public GitHub repository, e.g. damilola-birthday.
2. Upload index.html, the images folder, and ordinary-by-alex-warren.mp3.
3. In GitHub: Settings -> Pages.
4. Select "Deploy from a branch", choose main, folder /root, then Save.
5. GitHub will give you a public address ending in github.io.
6. Open that address on your phone and test the experience.

QR CODE
Once the GitHub Pages address is live, use that exact address as the QR destination.
The QR code should point to the webpage, not to the image files.

BEST PRESENTATION
Print the QR code on a small card with something like:
"Scan this when you're alone. ❤️"

The first screen deliberately requires a tap so the browser can start the music.
